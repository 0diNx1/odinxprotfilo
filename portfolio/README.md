# Portfolio: Md. Indadul Matubbar

## Put it on GitHub Pages
1. Create a repo named `0diNx1.github.io` and upload everything in this folder (keep `assets/`).
2. Settings > Pages > Source: `main` branch, `/ (root)` > Save.
3. Live at https://0dinx1.github.io/ (your /ctfteam/ site keeps working).

## Edit content
- Projects, certificates, CTF rows, articles: arrays at the top of `script.js`.
- About text, CV: `index.html`.
- Anything in orange dotted text is a placeholder: search for `[edit]`.
- CV PDF: click "Save as PDF / print" in the CV section and choose Save as PDF.
